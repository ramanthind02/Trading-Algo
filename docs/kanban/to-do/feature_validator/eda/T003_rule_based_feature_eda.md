# T003 — Rule-Based Feature EDA

## Goal
Build rule-based feature EDA infrastructure that computes per-level statistics with bootstrap confidence intervals for discrete signals (-1, 0, +1) generated by rule logic.

## Scope
In scope:
- Per-level statistics computation for discrete levels (-1, 0, +1):
  - Mean return
  - Volatility (std of returns)
  - Sharpe ratio: `mean / std`
  - Adjusted Sharpe ratio (if applicable from existing metrics)
  - Sample count per level
- Bootstrap confidence intervals (95%) for mean returns per level
  - Bootstrap resampling with replacement
  - Configurable number of bootstrap iterations (default: 1000)
- Level plot generation (bar chart showing performance by level)
- Transition matrix computation (optional diagnostic: how often does signal flip between levels)
- Data structures: `RuleBasedEDAStats`, `RuleBasedEDAPlots` dataclasses

Out of scope:
- Common EDA (descriptive stats, temporal stability, correlations) → T001
- Continuous feature EDA (decile analysis, distribution plots) → T002
- Binning models (rule-based features are already discrete)
- Report generation and aggregation → T004

## Data Contracts
- **Input schema:**
  - `feature: pd.Series` — Index: DatetimeIndex, Values: int (discrete levels: -1, 0, +1)
  - `target: pd.Series` — Index: DatetimeIndex (aligned with feature), Values: float (returns)
  - `levels: list[int]` — Expected discrete levels (default: [-1, 0, 1])

- **Output schema:**
  - `PerLevelStats.stats_by_level`: dict mapping level (int) → LevelStats
  - `BootstrapCIResults.ci_by_level`: dict mapping level (int) → BootstrapCI
  - `BootstrapCI.ci_lower`, `ci_upper`: 2.5th and 97.5th percentiles of bootstrap distribution (for 95% CI)
  - `TransitionMatrix.transition_counts`: 3x3 array (row=from_level, col=to_level)
  - `TransitionMatrix.transition_probs`: row-normalized probabilities (each row sums to 1.0)

- **Alignment expectations:**
  - Feature and target must have identical index
  - Feature values must be subset of `levels` (raise ValueError if unexpected level found)
  - Bootstrap resampling: sample with replacement from returns within each level group
  - Transition matrix: compute on consecutive pairs (feature[t], feature[t+1])

## Dependencies
- `pandas` — Series operations, groupby for per-level stats
- `numpy` — Array operations, bootstrap resampling (np.random.choice), percentile computation
- `scipy.stats` — Optional: percentile computation (np.percentile is sufficient)
- `matplotlib` — Bar plots for level stats, heatmaps for transition matrix
- `seaborn` — Optional for enhanced heatmap visualization

## Invariants / Constraints
- Deterministic: bootstrap must use fixed random seed for reproducibility (accept seed as parameter, default: 42)
- No lookahead: per-level statistics use aligned feature-target pairs only
- Immutability: all dataclasses frozen
- Level validation: feature values must be in `levels`, raise ValueError otherwise
- Sharpe computation: if `volatility == 0` for a level, set Sharpe to NaN
- Adjusted Sharpe: if not computed, set to NaN (or use same as Sharpe)
- Bootstrap CI validation: `n_iterations >= 100`, `0 < confidence < 1`
- Transition matrix: first timestamp has no previous state, exclude from transition counts

## Acceptance tests

**Unit tests** (location: `tests/validators/eda/test_rule_based_eda.py`):
- `test_per_level_stats_known_values()` — synthetic Series with hardcoded returns per level (-1, 0, +1), verify mean_return, volatility, Sharpe match hand-computed expected values
- `test_bootstrap_ci_deterministic()` — run bootstrap twice with same seed=42, verify identical `ci_lower` and `ci_upper` both times
- `test_bootstrap_ci_coverage_simulation()` — 1000-sample synthetic returns from known normal distribution, verify 95% CI contains true mean in ~95% of simulated draws
- `test_transition_matrix_rows_sum_to_one()` — synthetic 10-step signal sequence with known transitions, verify each row of `transition_probs` sums to 1.0
- `test_transition_matrix_counts_correct()` — signal sequence [−1, 0, 1, 0, −1], verify transition counts match expected 4-entry count matrix
- `test_level_plot_smoke()` — synthetic per-level stats and bootstrap CIs, verify bar chart Figure created without errors with error bars
- `test_edge_case_missing_level()` — feature never takes value +1, verify stats for +1 are either absent from dict or flagged as NaN/unreliable
- `test_invalid_level_value_raises()` — feature contains value 2 (not in [-1, 0, 1]) → raises ValueError
- `test_sharpe_zero_volatility_level()` — level with constant returns (std=0), verify Sharpe=NaN and no crash
- `test_low_sample_count_flagged()` — level with only 5 samples, verify `is_reliable=False` on LevelStats

**Integration tests:**
- Integration test: Not required (pure logic, covered by unit tests)
- Rationale: bootstrap CI, per-level stats, and transition matrix computations are self-contained algorithms that take a Series as input. There is no cross-module pipeline interaction requiring real data. The integration test for the full EDA pipeline in `tests/integration/feature_validator/test_eda_pipeline.py::test_rule_based_eda()` exercises these functions transitively when a rule-based bias node is used.

## Notes
- Test feature: Use synthetic rule-based feature (e.g., breakout signal) or convert RSI to discrete levels via simple threshold
- Bootstrap iterations: default 1000 (spec), allow user to configure
- Confidence interval: default 95% (2.5th and 97.5th percentiles)
- Random seed: default 42 for deterministic bootstrap
- Level plot: bar chart with 3 bars (one per level), error bars showing bootstrap CIs, annotate with sample counts
- Transition matrix heatmap: use seaborn heatmap or matplotlib imshow with color scale, annotate cells with probabilities
- Edge case: if a level has < 10 samples, flag as unreliable in stats (add `is_reliable: bool` field to LevelStats)
- Adjusted Sharpe: if ensemble/metrics module has adjusted Sharpe computation, use it; otherwise set to NaN or same as Sharpe
- Transition matrix interpretation: high probability of staying in same state (diagonal) vs frequent flipping (off-diagonal)
